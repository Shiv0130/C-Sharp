Programming 742 practice. Manual MVC CRUD (no scaffolding). Typical entities: Department / Employee.

**Open:** close VS → repo-root `to-net8.bat` (lab) or `to-net9.bat` (laptop) → then open the `.sln`.

If this folder arrived as a Lunga zip on net10, run repo-root `ingest-lunga.bat` and paste this folder path.
