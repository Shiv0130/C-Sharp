# Sem2 MVC labs (Programming 742)

Practice apps for EF Core relationships and manual CRUD (no scaffolding).

| Folder | What it is |
|---|---|
| `MVC_Crud_App` | Department / Employee style CRUD |
| `MVC_music` | Song / Artist / Genre |
| `mvcMovieWatchList` | Many-to-many watchlist |
| `mvcOfficeDeskAssign` | Desk assignment |
| `mvc_BloggingPlatform` | Author / BlogPost Restrict |

## Open on the wrong PC?

From the **repo root** (not from this folder):

- Lab: `to-net8.bat`
- Laptop: `to-net9.bat`
- Lunga zip: extract, then repo-root `ingest-lunga.bat`

Close VS before you run a bat.
